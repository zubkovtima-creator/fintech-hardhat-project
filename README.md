# Fintech Hardhat Project

Лабораторные работы по курсу **«Розробка Fintech додатків: Blockchain, криптовалюти, смарт-контракти»**.

## Что внутри

### 1. GrannyGift — смарт-контракт + Hardhat-тесты

Контракт `contracts/GrannyGift.sol`: бабуся вносит ETH и распределяет его между внуками; каждый внук может снять свою долю начиная со дня рождения (и после него).

Покрыто 8 тестов (`test/GrannyGift.test.js`):

1. Деплой контракта, внесение ETH и регистрация внуков
2. Корректное деление суммы между внуками
3. Успешное снятие в день рождения
4. Успешное снятие после дня рождения
5. Отказ при попытке снять до дня рождения
6. Отказ при повторном снятии
7. Отказ для постороннего аккаунта
8. Проверка события `GiftWithdrawn` с корректными аргументами

Результат: `8 passing`.

### 2. ProductRegistry — смарт-контракт + фронтенд

Контракт `contracts/Product.sol` — реестр продуктов с полями: название, описание, цена, адрес создателя, timestamp создания, URL картинки.

Фронтенд `frontend/index.html`:
- форма создания нового продукта;
- таблица со всеми продуктами: Назва / Опис / Ціна (ETH) / Адреса акаунта / Дата створення / Картинка.

Фронтенд работает в двух режимах:
1. **Через MetaMask** (если расширение установлено и настроено на сеть Hardhat Local, Chain ID 31337);
2. **Через прямой JSON-RPC** к `http://127.0.0.1:8545` — резервный режим, если MetaMask недоступен.

## Установка

```bash
npm install
npx hardhat compile
npx hardhat test

## Запуск фронтенда

Запустить локальную ноду Hardhat:
npx hardhat node

В отдельном терминале задеплоить контракт ProductRegistry:
npx hardhat run scripts/deploy.js --network localhost

Убедиться, что адрес из вывода совпадает с CONTRACT_ADDRESS в frontend/index.html.

Запустить HTTP-сервер для фронтенда:
npx http-server frontend -p 3000

Открыть в браузере: http://localhost:3000
